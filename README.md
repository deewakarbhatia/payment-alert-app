# Payment Alert App
A full-stack payment alert and record management system built with React, Node.js, MongoDB, Docker, Kubernetes, Terraform, Jenkins, Prometheus and Grafana.

## Tech Stack
- Frontend: React.js
- Backend: Node.js + Express
- Database: MongoDB
- Alerts: Twilio WhatsApp/SMS
- DevOps: Docker, Kubernetes, Terraform, Jenkins
- Monitoring: Prometheus + Grafana
- Cloud: AWS EC2 + S3
